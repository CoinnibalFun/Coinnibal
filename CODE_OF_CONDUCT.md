# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, and assume good faith. Harassment, personal attacks
and discriminatory language are not tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour to the maintainers at security@coinnibal.fun. All reports are reviewed and handled
confidentially.
